# **App Name**: TempMail Glass

## Core Features:

- Email Generation: Generates a new, random, disposable email address. Email addresses should persist for 24 hours.
- Real-time Email Display: Display received emails in real-time with a sleek, readable format.
- Copy to Clipboard: Copies the current email address to the user's clipboard for easy pasting.
- Dark Mode Toggle: UI toggle for switching between light and dark modes, with persistence to remember the user's preference.
- Address Reset: Provides a method for the user to manually clear the current email and generate a new address.

## Style Guidelines:

- Primary color: Dark blue (#3B82F6) for a modern and trustworthy feel.
- Background color: Very dark, desaturated blue (#111827) to support the dark mode theme.
- Accent color: Lighter blue (#60A5FA) to highlight interactive elements.
- Font: 'Inter', a sans-serif font, for a modern, clean, and readable UI.
- Implement a floating, rounded navigation bar. It should be positioned at the top on desktop and at the bottom on mobile.
- Use a glass morphism effect to make UI elements appear translucent, allowing background elements to be visible but blurred.
